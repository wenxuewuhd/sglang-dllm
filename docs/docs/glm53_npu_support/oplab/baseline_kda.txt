=== sweep: does anything in a KDA layer depend on sequence length? ===
  KDA is recurrent.  Its decode state is a fixed [64,128,128] fp32
  matrix per slot plus a [3,24576] conv window; the sequence length
  enters no shape, no stride and no loop bound.  First we prove that,
  then we measure all four lengths anyway.

  n=    1024: 12 tensors  (reference fingerprint)
  n=    4096: IDENTICAL to n=1024
  n=   32768: IDENTICAL to n=1024
  n=  131072: IDENTICAL to n=1024

  So any spread below is this machine's noise floor, not an n effect.
  (An honest O(1) claim has to be structural.  Measuring four identical
   workloads and finding them equal proves nothing on its own.)

     seq len   us/layer   x34 (ms)  vs shortest
      n=1024     291.57      9.913        +0.0%
      n=4096     292.38      9.941        +0.3%
     n=32768     298.33     10.143        +2.3%
    n=131072     291.49      9.911        -0.0%

  finished.  There is no kernel work left to win there -- only fewer bytes
